# HELPUA24 · серіальний explainer 9:16

Референс: 115 с, 1080×1920, 30 fps, один диктор, ~20 сцен по 4–7 с, жорсткі склейки.
Тема змінюється — **монтаж, ритм і візуальна мова ні**.

Код: `name/src/Series/kit.tsx` (кіт) і `name/src/Series/EpisodeTemplate.tsx` (робочий приклад,
композиція `Series-Template`). Нове відео = копія шаблону + нові `scenes`. Кіт не форкати.

## 1. Формула монтажу (не міняти)

| Параметр | Значення |
|---|---|
| Формат | 1080×1920, 30 fps, h264 crf 17, yuv420p |
| Тривалість | 100–120 с (сума сцен = тривалість голосу + ~1 с хвіст) |
| Сцен | 18–22, у середньому 5–6 с; хук ≤ 4 с |
| Склейки | жорсткі (cut), без кросфейдів; на першому кадрі сцени 3-кадровий білий «удар» (вже в `SceneShell`) |
| Рух усередині сцени | повільний push-in 1.00→1.07 (`PushIn`) + «поп» елементів пружиною |
| Голос | один диктор, впевнений подкаст-тон, без музики поверх речень; опційно тихий тривожний бед −22 dB |
| Титри | 1–3 слова, нижня третина (y≈1480), Oswald 700 uppercase, біле; **1 ключове слово на фразу — помаранчеве (`hot`)** |
| Безпечні зони | права ~150 px і нижні ~220 px вільні для інтерфейсу платформи; ніколи не відтворювати водяний знак з референсу |

## 2. Структура історії (по актах)

1. **Пролог/хук (0–4 с)** — питання або «уяви…», друкарська машинка, холодний синій. Без вступів і логотипу.
2. **Акт I «calm/tense» (≈ 0–35 %)** — хто/що, декорації, інтрига; сині/сині-фіолетові тони.
3. **Акт II «crisis» (≈ 35–80 %)** — ескалація: червоний градінг, таймери, лічильники, штампи, «розбухання» наслідків.
4. **Акт III «finale» (≈ 80–100 %)** — результат, розплата, висновок; бурштиновий. Останні 2 сцени — повернення до людини/мораль + крок-запрошення на «наступну серію».

Кожна сцена = **одна ідея = одне речення диктора = один візуал**. Якщо в реченні дві ідеї — розбий на дві сцени.
Назва сцен у HUD нумерується: `ЭПИЗОД NN · НАЗВА` — навіть якщо це «розділ», а не серія.

## 3. Візуальна мова

- **Фон**: `Backdrop` (радіальний глоу кольору акту) + `Particles` + `Vignette` — завжди, на кожній сцені.
- **Палітра** (`ACTS`): calm `#060b14/#3fb6ff`, tense `#080a12/#8fb8ff`, crisis `#120406/#ff3b30`, finale `#0a0805/#ffa42b`. Акцент титрів — `#ff9a1f`.
- **Ілюстрація**: плоский вектор (CSS/SVG), заокруглені силуети без облич (капюшони, силуети), м'які тіні/глоу. **Жодних фото й сток-відео.** Документи — світлі аркуші з нахилом −2°, тінь `0 40px 100px #000`.
- **HUD** (`HudBar`): зліва червона блимаюча крапка + `ЕПІЗОД NN · НАЗВА` (mono, caps, muted); справа `ДАТА  ЧАС:ХВ:СЕК`: тікає в межах сцени, на склейці стрибає до часу сюжету (як у референсі); під ним 1 рядок-підпис кольору акту.
  Дата/час мають **рухатись сюжетом** (хронологія події) — це головний «серіальний» прийом.
- **Бібліотека прийомів** (усі в `kit.tsx`): `Typewriter` (термінал), `ScanBox` (ID-рамки на силуетах), `Stamp` (штамп «ляпає»),
  `CountUp` (гроші/жертви), `Glitch` (RGB-розмазування на ударі), `Pop` (поява). Нові — складати з них; додавати в кіт, лише якщо повториться ≥ 2 разів.
- Типові візуали на сцену: термінал із кодом; мережа вузлів; ілюстрація будівлі/міста за градієнтом неба; браузер/вікно ОС із прогресом; flip-таймер `02:23:59:58`;
  гаманець/монети з лічильником; плакат «розшукується» з пікселізованим фото; фінальне «замок/двері/тінь».

## 4. Конвеєр виробництва (по кроках)

1. **Сценарій (укр/ру — мовою відео)**: ~280–320 слів на 2 хв (≈2.7 слова/с). Короткі речення. Хук-питання. Дати й час прив'язані до сцен.
2. **Розкадровка у таблицю**: `id | секунди | акт | HUD (епізод/дата/час/нота) | речення | ключове слово | візуал | прийоми`.
   Показати користувачу на затвердження **до** кодингу, якщо тема нова.
3. **Озвучка (ElevenLabs)**: голос — `Maks Tsukrenko – Confident Podcast` (вже в `public/audio/`, або новий через `creative_list_voices`).
   Генерувати **цілим файлом** → `public/audio/<ep>.mp3` (одна інтонація, без швів). Ліміт: не повторювати генерацію без потреби — платна.
4. **Таймінги слів**: `creative_transcribe_audio` (або `@remotion/captions` — див. скіл `remotion-captions`) → слова з `start`. Перерахувати в кадри (`round(start*30)`), відняти старт сцени → `words[].at`. Межі сцен ставити на паузи/початки речень; `seconds` сцени = до початку наступного речення.
5. **Код**: `cp EpisodeTemplate.tsx EpisodeNN.tsx`, заповнити `scenes`, візуали — окремі компоненти. Зареєструвати `Composition` у `Root.tsx` (`durationInFrames={totalFrames(scenes)}`), `<Audio src={staticFile(...)} />` додати в обгортку.
6. **Перевірка**: `npm run lint` → `npx remotion still ... --frame=N` на кожен акт (див. §6) → повний рендер.
7. **Рендер**: `npx remotion render src/index.ts <Id> out/<id>.mp4 --codec=h264 --crf=17 --pixel-format=yuv420p --concurrency=2`. Додати крок у `.github/workflows/verify-remotion.yml` (там рендеряться всі серії).

## 5. Контрольний список якості

- [ ] У кожній сцені видно HUD, титри не перекривають головний об'єкт (якщо візуал займає низ — `captionY: "mid"`).
- [ ] Не більше 3 слів у титрі; слово з'являється ≤ 2 кадрів від звучання.
- [ ] Хоча б 1 «ударний» момент на акт (штамп, глітч, лічильник, вибух кольору).
- [ ] Акти змінюють колір: видно перехід синій → червоний → бурштиновий.
- [ ] Таймкод у HUD відповідає хронології сюжету (стрибає лише вперед у межах однієї дати).
- [ ] Усі текстові дані (суми, дати) — з одного джерела істини (константи), без розбіжностей між сценами.
- [ ] Сума `seconds` ≈ довжина аудіо.
- [ ] Реальні люди/організації: лише факти з перевірених джерел, без звинувачень; обличчя не малювати.

## 6. Рендер у цьому середовищі

`npx remotion browser ensure` тут не працює (хост remotion.media недоступний). Для превʼю кадрів:

```bash
npx remotion still src/index.ts Series-Template out/f.png --frame=100 --scale=0.5 \
  --browser-executable=/opt/pw-browsers/chromium --chrome-mode=chrome-for-testing
```

Повний рендер — у GitHub Actions (workflow вже налаштований) або локально.
